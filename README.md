# Website Template

A lightweight, personal starter template containing my most commonly used setup for standard web projects.

## Structure

All three core files are intentionally placed on the **same directory level** and are already pre-linked:

```text
├── index.html   # Basic HTML5 boilerplate (meta tags, title, linked CSS & JS)
├── styles.css   # Default stylesheet setup
└── script.js    # Base JavaScript file
```

## Usage

1. Clone or download this repository.
2. Keep `index.html`, `styles.css`, and `script.js` in the same folder so the relative links work out of the box.
3. Update the `<title>` and start building.
